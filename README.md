歌詞系統から選べる楽曲推薦アプリです。

## まとめて再生機能

表示中の曲順でまとめて再生します。
ライブラリやプレイリストへの追加は行われません。
再生待ちのキューは置き換わります。
Apple Musicの契約が必要です。

配信対象外として登録されている曲は対象外です。
画面が切り替わらない場合は、Safariで開き、ショートカット名が一致しているか確認してください。
実行許可が表示されたら内容を確認して許可します。

追加したショートカットの名前は「キュー追加」にしてください。

## ショートカットの作り方

1. ショートカットの名前を「キュー追加」にする。
2. 「テキストを分割」を追加し、入力に変数「ショートカットの入力」、区切りに「新しい行」を指定する。
3. 「各項目を繰り返す」を追加し、分割したテキストを渡す。
4. 繰り返しの中に「iTunes Storeで検索」を置く。検索する値は「繰り返し項目」、カテゴリは「ミュージック」、検索基準は「製品ID」、地域は「日本」にする。
5. 「繰り返しの終了」の下に「ミュージックを再生」を置き、再生対象を「繰り返しの結果」にする。
